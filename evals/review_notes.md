# Подсказки к ревью тестового набора

Автоматический просмотр всех 86 вопросов `evals/questions.jsonl` с полным
текстом их пунктов и соседних пунктов кодекса. Это не ревью: отметки
`verified` здесь не ставятся, решение по каждому вопросу — за человеком.
Около 70 вопросов, включая все 10 без ответа в кодексе, замечаний не вызвали.

Правка в `evals/review.py`: команда `e`, затем пункты через пробел (`83/` —
пункт без номера). Правка снимает отметку, после неё нужно `v`.

```bash
.venv/bin/python evals/review.py real_013 real_005 syn_044 real_009 syn_016 real_004 syn_026 syn_045 real_001 real_007 real_008
```
